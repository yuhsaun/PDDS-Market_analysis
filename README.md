# PDDS-Market_analysis

Team 8 | Sales and Market Basket Analysis dashboard

## Team
- Tina: revenue by product each month
- Ning: customers by total-spend range
- Amelia: product pairs bought together

## Repo structure
- `data/` the SQLite database (`sales.db`)
- `prototypes/` each member's chart prototype, one file per person
- `requirements.txt` Python packages the dashboard needs
- `app.py` the final dashboard (added later, together)

## How we work
1. Don't edit the `main` branch directly.
2. Create your own branch for each piece of work, e.g. `tina-revenue-chart`.
3. Commit your changes with a short message, e.g. "add revenue chart".
4. Open a Pull Request (PR) to merge your branch into `main`.
5. A teammate reviews the PR, then clicks "Merge pull request".
6. Before starting new work, pull the latest `main`.
